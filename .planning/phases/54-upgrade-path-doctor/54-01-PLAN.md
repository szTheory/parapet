<objective>
Add ONE new static check named `schema` to `mix parapet.doctor` that folds two signals into a single finding: (1) config drift — runtime `:schema_prefix` vs compiled `@schema_prefix`; (2) schema existence — is the configured schema present in the live repo. This is the primary detection backstop for the UPG-05 recompile footgun (D-05, load-bearing): it moves the compiled-vs-data split left from "loud failure at first prod query" to "caught by `mix parapet.doctor --ci` in the upgrade branch."

Purpose: Satisfy DOCTOR-01. Existing adopters who run `mix parapet.doctor` on upgrade (per `docs/migration-v1.md`) get a meaningful check that catches the stale-compile drift the Elixir `compile_env` boot-check cannot see (it fires only for explicitly-set config that drifts, never an unset key whose library default changed — D-17).
Output: Extended `parapet.doctor.ex` (~40 lines, zero framework change) + a unit test file.
</objective>
