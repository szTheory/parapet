## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → LiveView socket | `phx-click="confirm_mitigation"` events from browser carry `step`, `incident_id`, `token` in params. All other state (payload, hash, capability resolution) is server-side. |
| LiveView render → adopter UI | The four flash strings are user-visible. The verbatim `{:conflicted, _}` string is contractually pinned by ROADMAP success criterion #2. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-LV-01 | Information Disclosure | Unknown `:short_circuited` reason atom (e.g., from a future vocab addition) leaking via `inspect/1` or untrusted string interpolation | mitigate | `short_circuit_flash/1` is a closed-clause private function — no string interpolation, no `inspect`. Unknown atoms raise `FunctionClauseError` (caught by Phoenix's standard exception handler, surfacing a generic error page). This is the correct failure mode — better to fail loudly than to leak a raw atom into the UI. |
| T-25-LV-02 | Tampering | Browser-supplied `target_refs_hash` round-trip via `phx-value-*` (the rejected D-12 option) | mitigate | The hash is NOT round-tripped through `phx-value-*` (D-12 + Pitfall 6 — LiveView-assigns option chosen). The server recomputes the hash from canonical TimelineEntry storage on Confirm. |
| T-25-LV-03 | Spoofing | LiveView event from unauthenticated session | accept | Adopter app owns operator authentication; ActionPayload `actor` field is informational only. Phase 25 doesn't add new access-control gates. |
| T-25-LV-04 | Information Disclosure | Capability name leaking PII into the Action cell | accept | Capability names are adopter-controlled strings (`Parapet.Capabilities.register_recovery/2 :name` opt). If an adopter writes PII into `name`, that's an adopter-side concern, not a Parapet defect. Documented in adopter-facing docs (Phase 29 ADOP-03). |
| T-25-LV-SC | Tampering | npm/pip/cargo installs | mitigate | N/A — Phase 25 installs zero new packages. |
