<objective>
Make generated Operator UI route construction scope-aware while keeping route ownership in generated host-owned code.

Purpose: UIROUTE-01 requires every local Operator UI link, patch, redirect, and route helper to respect a host-owned mount such as `/ops/parapet`; UIROUTE-03 requires doing that without changing auth ownership, router ownership, public API tier, dependency surface, or the Phoenix/LiveView compile-out boundary.

Output: generated templates derive `operator_base_path` from the current LiveView URI, default to `/parapet`, pass the base path into route-producing components, and prove default plus scoped behavior with generated source and render tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| current LiveView URI -> generated local route helpers | The current request path is untrusted input used to derive local paths |
| generated queue params -> patch href query strings | Queue state crosses from params into local links |
| generated host-owned UI -> Parapet core | Optional UI support must not create Phoenix/LiveView runtime coupling in Parapet core |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-38-01 | Elevation of privilege | generated local navigation under scoped host auth | mitigate | Derive `operator_base_path` from the current URI path and assert scoped renders do not emit unscoped `/parapet` local links. |
| T-38-02 | Tampering | `push_patch` / `push_navigate` targets | mitigate | Build local paths only from normalized path segments through final `parapet`; never use URI scheme, host, query, or params as a target. |
| T-38-03 | Tampering | queue pagination/query links | mitigate | Preserve `URI.encode_query/1` and existing nil/empty/active filtering while adding base-path argument tests. |
| T-38-04 | Information Disclosure | external observability/action links | mitigate | Keep `external_link_url/1`, trace URL templates, and action item resolver URLs outside `operator_base_path` rewriting. |
| T-38-SC | Tampering | package/dependency surface | mitigate | No package-manager installs are allowed; verify no `mix.exs` or `mix.lock` dependency change is introduced by this plan. |
</threat_model>
