| Property | Value |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Theme-control internal gaps, chip padding, inline icon/text gaps if existing markup keeps them |
| sm | 8px | Compact link padding, nav item gaps, small stacked text gaps |
| md | 16px | Card padding, mobile page padding, default grid gaps |
| lg | 24px | Desktop card padding, section gaps, route proof panels |
| xl | 32px | Desktop page horizontal padding |
| 2xl | 48px | Major vertical separation if a new proof-only section is required |
| 3xl | 64px | Page-level spacing; do not introduce new 64px gaps in Phase 38 unless preserving existing layout |

Exceptions: preserve existing generated dimensions only: `min-h-[40px]` for links/buttons, `min-h-[32px]` for nested theme buttons, `22rem` detail/action side columns, and `min-h-[28rem]` empty detail panel. New scoped-route controls, if any, must use `min-h-[40px]`.

## Typography

Use only these typography roles for modified or newly generated route-facing markup. Do not add new display styles for this phase.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 | 1.5 |
| Label | 12px | 600 | 1.5 |
| Heading | 18px | 600 | 1.2 |
| Display | 30px | 600 | 1.2 |

Route-scope changes must preserve existing copy hierarchy. Route helper refactors must not change visible heading levels, nav labels, button labels, or link copy except where a scoped mounting example is needed in generated router guidance.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f5f5f4` light / `#12100d` dark | Page background and full-height Operator UI canvas |
| Secondary (30%) | `#ffffff` light / `#1c1917` dark | Cards, nav/header surfaces, detail panels |
| Accent (10%) | `#0f766e` light / `#2dd4bf` dark | Active nav state, focus rings, selected queue affordance, local Operator UI route links, queue refresh CTA |
| Destructive | `#881337` text on `#ffe4e6` light / `#fecdd3` text on `#4c0519` dark | Destructive or danger status indicators only; do not use for scoped-route links |

Accent reserved for: active Operator nav item, `po-focus` rings, selected incident row border/background, "Load Latest Changes", back links, and other local Operator UI links that navigate within the generated workbench. External links keep `po-link` blue. Scoped-route work must not introduce a new accent color or recolor existing controls.

## Copywriting Contract

| Element | Copy |

| Element | Copy |
|---------|------|

Do not add explanatory in-app text about route scopes. Scoped route examples belong in generated router guidance or docs comments, not in the live Operator UI.

## Phase Interaction Contract

| Surface | Required Behavior |
|---------|-------------------|
| Base path ownership | Generated host-owned code owns `operator_base_path`; default is `/parapet`, scoped proof path is `/ops/parapet`. |
| Base path derivation | Derive from the current LiveView URI in `handle_params/3` or use an explicit generated editable helper. The result must be passed into every route-producing component assign that needs it. |
| Navigation semantics | Keep same-LiveView queue/history transitions on `patch` or `push_patch`; keep detail LiveView transitions on `navigate` or `push_navigate`. |
| Route surfaces | Cover `push_patch`, `push_navigate`, `navigate`, `patch`, `href`, back links, nav links, queue pagination, queue item links, history links, resolved incident links, and incident detail links. |
| Form surfaces | Audit submit/form route surfaces. Do not add form-route behavior unless an existing route-bearing form action is found. |
| External links | Do not rewrite external URLs, `target="_blank"` links, telemetry/provider links, or `external_link_url/1` outputs through the Operator base path. |
| Demo copy | Demo generated-copy files must render the same scoped routes as generator output for `/parapet` and `/ops/parapet`. Template/demo drift is a failure. |
| Auth/router ownership | Do not add Parapet-owned router modules, auth hooks, public stable APIs, or core Phoenix/LiveView dependencies. Host scopes and pipelines remain host-owned. |

Route helpers must emit no literal local `/parapet` path when the current mount is `/ops/parapet`, except in documented default-mount examples and fallback defaults.
