<objective>
Establish the three-primitive sleep vocabulary that makes the suite's remaining
`Process.sleep` calls honest (D-16), closing TEST-04 and TEST-05:

1. Add `assert_eventually/2` to `ConcurrencyCase` — the deterministic async-settle helper
   that re-raises the real assertion diff on timeout (TEST-05, D-12–D-15).
2. Replace the cluster-smoke startup `Process.sleep(200)` with a bounded `SELECT 1`
   readiness barrier that fails loud with a DX message (TEST-04, D-07/D-08).
3. Annotate all six intentional-hold call sites with the greppable two-line
   `INTENTIONAL HOLD:` convention and a per-file `@concurrency_hold_ms` attribute
   (TEST-04, D-09/D-10/D-11).
4. (Discretionary, D-17) Add a cheap non-blocking grep guard so a future bare
   `test/` sleep is flagged.

Purpose: After this plan every surviving `Process.sleep` in `test/` is one of three
named primitives — a synchronous start-barrier, an annotated deliberate hold, or an
`assert_eventually`-replaceable settle — so "honest green suite" is a defensible claim
rather than a suite riddled with unlabelled timing hacks.

Output: One new test-support `def`, one readiness barrier, six annotated hold sites, and
one small grep-guard script.
</objective>
