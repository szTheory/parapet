<objective>
Make the two operational caller surfaces consume the structured archive result contract from Plan 01: the Mix task prints honest machine-readable summary JSON or fails nonzero, and the optional Oban worker preserves the same success/error tuple for retry and dead-job diagnosis.

Purpose: ARCH-02 and ARCH-04 require failure visibility outside the library function. A correct core archiver is not enough if the CLI still prints static success or if worker tests only prove `{:ok, :ok}`.

Output: `mix parapet.archive` emits a summary JSON object on success and raises on failure, while `Parapet.Evidence.ArchiveWorker.perform/1` remains compile-gated and returns `{:ok, %Summary{}}` or `{:error, %Failure{}}`.
</objective>
