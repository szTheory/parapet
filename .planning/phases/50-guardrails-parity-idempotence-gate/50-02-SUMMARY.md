## What Was Built

### Task 1 — Shared CAPTURES array + `--manifest` mode

Refactored `capture_operator_ui_screenshots.sh` to extract all 15 `capture …` call sites into a single `CAPTURES` bash array (`name|size|path|theme` per element). A single dispatch loop replaces the 15 duplicated calls. The existing `capture()` function is unchanged.

Added `--manifest` flag: when set, the script prints a 5-column Markdown table (`name | route | viewport | theme | scenario`) with no Chrome, no server, no DB, then `Total: 15 captures`, then exits 0. Detail routes use `/parapet/incidents/:detail_id` as a DB-free placeholder; capture mode substitutes the resolved `$DETAIL_ID` at dispatch time (`path="${path/:detail_id/$DETAIL_ID}"`).

The `--manifest` guard exits before the Chrome-find block, `mkdir`, curl reachability check, and the `DETAIL_ID` DB query — ensuring zero infra requirements.

### Task 2 — `operator-ui-baseline.md`

Created `examples/demo_app/scripts/operator-ui-baseline.md` with:
- Header prose noting the file is generated by `--manifest`
- Verbatim `--manifest` block (byte-identical to script stdout, `sed`-extractable via `/^| name /,/^Total: /p`)
- `## Re-run & compare` section: seed → start → capture to tmpdir → eyeball → update baseline (no PNGs committed)
- `## CI manifest-drift check` section showing the exact `diff` command CI runs

No PNGs, no content hashes. Repo stays raster-free (D-15).

### Task 3 — CI `manifest-drift` step

Added "Operator UI manifest drift" step to the `lint` job (the Postgres-free quality job) after "Verify Public API". The step runs:
```bash
diff \
  <(bash examples/demo_app/scripts/capture_operator_ui_screenshots.sh --manifest) \
  <(sed -n '/^| name /,/^Total: /p' examples/demo_app/scripts/operator-ui-baseline.md)
```
Non-zero diff fails the build. No new services, no Chrome, no DB (D-17).
