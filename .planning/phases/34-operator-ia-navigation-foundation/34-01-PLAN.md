<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| generator -> host app | Generated LiveView files become host-owned application code and must not introduce Parapet-owned auth or router semantics. |
| route guidance -> adopter router | Adopters copy route snippets into authenticated scopes; incorrect guidance can expose UI or break deep links. |
| generated direct detail -> stable Operator API | Generated UI calls stable `Parapet.Operator` read/mutation seams and must not invent new API semantics. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-34-01 | Spoofing | Generated route guidance | mitigate | Preserve authenticated-scope guidance and `Parapet does not provide its own auth`; do not add Parapet-owned router/auth modules. |
| T-34-02 | Tampering | Detail route migration | mitigate | Add tests that pin both preferred `/parapet/incidents/:id` and compatibility `/parapet/:id` route guidance. |
| T-34-03 | Repudiation | Mutating action handlers | mitigate | Leave `Parapet.Operator.ActionPayload` construction and audited `Parapet.Operator` calls unchanged while only changing post-action navigation path. |
| T-34-04 | Denial of Service | Active queue refresh | mitigate | Preserve operator-paced `Load latest changes` behavior; do not introduce silent background queue reorder. |
</threat_model>
