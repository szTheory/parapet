<objective>
Extend `mix parapet.install` so a single `--schema`/`--no-create-schema` routes through `group: :parapet` to the composed `gen.spine`, completing the install leg of the shared resolver (GEN-05) and the flag surface (GEN-04) without introducing a second config-write or resolution path.

Purpose: `install` is the orchestrator adopters actually run. GEN-05 requires the *same* resolver drive install as the standalone generators — which, per the verified Igniter routing semantics, means declaring the flags with `group: :parapet` and letting the composed `gen.spine` do the resolving and config write. This plan owns only `install.ex`, so it runs in Wave 2 parallel to the generators (Plan 02) and the committed migrations (Plan 04).
Output: extended `install.ex` Info + a routing/forwarding test.
</objective>
