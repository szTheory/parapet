<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI `--schema` → generated migration heredoc | Operator-supplied identifier is interpolated into a `CREATE SCHEMA` SQL string and `prefix:` opts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-53-02 | Tampering | `--schema` value → sentinel `CREATE SCHEMA` string + `prefix:` literals | high | mitigate | The value is resolved through `Parapet.Spine.Schema.resolve_prefix` (Plan 01), which runs `normalize/1` → `safe_ident!/1` (allowlist `^[a-z_][a-z0-9_]*$`, ≤63 bytes) before it can be interpolated — an injection payload raises `ArgumentError` at resolve time, never reaching the heredoc. |
| T-53-SC | Tampering | npm/pip/cargo installs | low | accept | No new packages introduced this phase (RESEARCH: "No new packages"). No install tasks; supply-chain checkpoint not applicable. |

No high-severity threats remain open: the only untrusted-input path is gated by the shared allowlist.
</threat_model>
