<objective>
Give contributors a single `mix ci` command that mirrors the portable CI gate locally, wire CI to call that same alias so local and CI cannot drift, and update CONTRIBUTING.md to document the command plus the three known local-vs-CI deltas. Also land the Phase 59 PLT prerequisites (dialyzer `plt_file` config + `.gitignore` entry).

This phase is wiring, not building — every step and tool it composes already exists and runs verbatim in the current CI `lint` job. No new tooling, no dependency changes, no wrapper scripts.

Purpose: Honest local signal (`mix ci` green ⇒ portable CI gate would pass) with a single source of truth (`mix.exs`), and clear delta documentation so a contributor never mistakes an expected CI-only failure for a regression.
Output: Populated `ci` mix alias, `lint-once` CI job, updated `needs` lists, dialyzer `plt_file` config, `/priv/plts/*.plt*` gitignore entry, rewritten CONTRIBUTING sections.
</objective>
