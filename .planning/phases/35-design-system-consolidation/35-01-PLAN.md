<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| generated template -> host app | `mix parapet.gen.ui` copies generated LiveView code into host-owned app files. |
| mutating control -> audited Operator API | Generated controls call stable `Parapet.Operator` mutation seams and must communicate audit/risk before the operator clicks. |
| demo mirror -> adopter expectation | Demo copied UI should represent the same generated surface adopters receive. |
| design-system helper -> dependency surface | Helper consolidation must stay local and must not add new UI dependencies or runtime configuration. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-35-01 | Spoofing | Generated UI ownership | mitigate | Keep generated UI host-owned and preserve authenticated-scope/router guidance; do not add Parapet-owned auth/router code. |
| T-35-02 | Repudiation | Mutating action cards | mitigate | Require pre-click audit/risk copy and preserve `Parapet.Operator.ActionPayload` mutation paths. |
| T-35-03 | Tampering | Design-system helper consolidation | mitigate | Keep helpers private/local and pin generated helper names/classes through source-contract tests. |
| T-35-04 | Denial of Service | Motion/layout behavior | mitigate | Keep `transition-all` absent and restrict active press scaling to explicit buttons/action links so rows/cards do not resize or shift. |
| T-35-05 | Information Disclosure | External action item links | mitigate | Preserve `target="_blank"` plus `rel="noopener noreferrer"` and require evidence-review copy before external recovery. |
</threat_model>
