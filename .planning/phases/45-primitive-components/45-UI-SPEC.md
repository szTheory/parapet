# Phase 45 — UI Design Contract: Primitive Components

> Visual and interaction contract for re-skinning the primitive components in
> `priv/templates/parapet.gen.ui/operator_components.ex.eex` (and its demo mirror).
> Generated by gsd-ui-researcher; verified by gsd-ui-checker.
>
> **This is NOT a greenfield design.** Every token value below is derived verbatim
> from the LOCKED v1.5 brand book (`brandbook/tokens/tokens.css` + `tokens.json`).
> Do not re-litigate palette, typography, spacing, or radius. Implement from this
> contract without design ambiguity.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (EEx templates + inline CSS custom properties) |
| Preset | not applicable |
| Component library | Phoenix HEEx function components (host-owned, generated) |
| Icon library | Inline SVG, `currentColor`, always accompanied by visible text label |
| Font | IBM Plex Sans 400/500/600 + IBM Plex Mono 400/500 (self-hosted woff2, vendored Phase 44) |

**Theme mechanism:** `data-parapet-theme` attribute (`"light"` / `"dark"` / `"system"`).
All token values live in CSS custom properties inside `operator_theme_bootstrap/1`.
Phase 45 adds NO new CSS variables — it applies existing `--po-*` and `--parapet-*`
vars to component class rules that currently use raw Tailwind color utilities.

## Spacing Scale

Source: `brandbook/tokens/tokens.css` §9.2 (8px grid, locked).

| Token | Value | Usage in primitives |
|-------|-------|---------------------|
| `--space-1` | 4px | Icon-to-label gap, chip inner x-padding tight |
| `--space-2` | 8px | Chip inner padding (`px-2 py-1`), button icon gap |
| `--space-3` | 12px | Compact button padding (`px-3 py-2`) |
| `--space-4` | 16px | Default button padding (`px-4 py-2`), card inner |
| `--space-5` | 24px | Card padding, section gap |
| `--space-6` | 32px | Large card padding, major gap |
| `--space-7` | 48px | Section break |
| `--space-8` | 64px | Page-level only |

**Exceptions:**
- `--space-3` = 12px is a multiple of 4 (4×3), the 8px-grid midpoint from the locked
  brand scale in tokens.css, used for compact control padding (`px-3`). It is a locked
  brand token, not a Phase-45 spacing invention.
- Touch-target minimum for interactive controls: `min-h-[40px]` (already in
  `control_base()` and `nav_item`). Retain for all button/nav/theme-option controls.
- Chips/badges/pills are exempt from 40px height — they are non-interactive display
  elements. Min height is not required.
- Stat/metric card numbers are display-only; no touch-target padding needed.

## Typography

Source: `brandbook/tokens/tokens.css` §8.3 (locked). Only roles used by primitive
components are listed.

> **Locked-brand exception:** Type sizes are locked v1.5 brand tokens (tokens.css),
> not Phase-45 choices; metric tokens are numeric-display-only and sit outside the
> 4-tier UI prose scale.

### UI prose type scale (4 tiers)

These are the four sizes used for actual UI prose — labels, button text, links, and
body copy in the primitive components.

| Role | Token | Size | Weight | Line Height | Usage |
|------|-------|------|--------|-------------|-------|
| Caption / label | `--fs-caption` | 12px | 500 (`--fw-caption`) | 1.40 | Chip text, badge text, pill text, stat-card label |
| Body small | `--fs-body-sm` | 14px | 400 (`--fw-body-sm`) | 1.50 | Button label, link text, theme-switcher option |
| Body | `--fs-body` | 16px | 400 (`--fw-body`) | 1.60 | General body, card body copy |
| Metric large | `--fs-metric-lg` | 36px | 500 (`--fw-metric-lg`) | 1.00 | Primary stat/metric number (numeric display) |

### Numeric-display-only tokens (outside the 4-tier prose scale)

These render numbers, never prose. They are locked brand tokens, exempt from the
4-tier UI prose scale above.

| Role | Token | Size | Weight | Line Height | Usage |
|------|-------|------|--------|-------------|-------|
| Metric small | `--fs-metric-sm` | 20px | 500 (`--fw-metric-sm`) | 1.10 | Stat-card secondary metric value (numeric only) |

**Weights — primitives declare exactly two:** regular **400** and medium **500**.
Weight **600** appears only where the locked brand token already sets it (e.g.
`--fs-h1`..`--fs-h3` headings inherited by composing components and the IBM Plex Sans
600 face vendored in Phase 44); it is a brand-token passthrough value, NOT a separately
declared primitive weight. Primitives themselves declare 400/500 only.
Avoid weight-only distinction for state; always pair with color or shape.

**Font family:** All UI text uses `var(--font-sans)` = `"IBM Plex Sans", ui-sans-serif, system-ui, sans-serif`.
Monospace content (IDs, trace IDs, code values, external IDs in action-item cards)
uses `var(--font-mono)` = `"IBM Plex Mono", ui-monospace, monospace`.

## Focus Ring Contract (COMP-06, A11Y-01)

| Surface | Ring color | Offset color | Ratio | CSS custom property |
|---------|------------|--------------|-------|---------------------|
| Light (any) | `#256C82` | `#FFFFFF` | 5.92:1 on white panel (AA) | `--po-focus` / `--po-focus-offset` |
| Dark (any) | `#F8F4EC` (limestone) | `#18232B` | 14.57:1 on deep-slate bg (AAA) | `--po-focus` / `--po-focus-offset` |

**Implementation rule:** All interactive elements use `class="... po-focus focus:outline-none focus:ring-2 focus:ring-offset-2"`. The `.po-focus` class is already defined in `operator_theme_bootstrap/1` as:
```css
.parapet-ui .po-focus {
  --tw-ring-color: var(--po-focus);
  --tw-ring-offset-color: var(--po-focus-offset);
}
```
Phase 45 replaces any hard-coded `focus:ring-{color}-{n}` utilities on buttons and
controls with `po-focus` + the Tailwind ring utilities. The CSS variable does the
theme-correct color switching automatically.

### Links (COMP-03)

All anchor links use `.po-link` class. Do not hard-code link colors.

```css
.parapet-ui .po-link { color: var(--po-link); }
.parapet-ui .po-link:hover { color: var(--po-link-hover); text-decoration: underline; }
```

Focus: `.po-link` elements also carry `po-focus` for keyboard visibility. External
links (`target="_blank"`) include `rel="noopener noreferrer"` (already present in
template). Icon (`&nearr;` or SVG) is decorative `aria-hidden="true"`.

## Motion Contract (MOTION-02)

| Interaction | Duration | Easing | CSS |
|-------------|----------|--------|-----|
| Button hover/active (press scale) | `var(--motion-fast)` = 120ms | `var(--motion-ease)` = cubic-bezier(.2,0,0,1) | `transition-transform duration-[--motion-fast] ease-[--motion-ease]` |
| Color transitions (link hover, nav hover) | `var(--motion-fast)` = 120ms | `var(--motion-ease)` | `transition-colors duration-[--motion-fast] ease-[--motion-ease]` |
| Theme switcher selected state | instant (no transition) | — | no transition class |

**Prohibitions:**
- No `transition-all` — it catches opacity, layout, and color together and causes thrash.
- No decoration-only transitions (fades, spins on non-loading elements).
- `active:scale-[0.96]` is the only press affordance — do not add bounces or overshoots.

**Reduced motion:** Already zeroed in `prefers-reduced-motion` block:
```css
@media (prefers-reduced-motion: reduce) {
  :root { --motion-fast: 0ms; --motion-base: 0ms; }
  .parapet-ui * {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```
`duration-[--motion-fast]` reads `0ms` under reduced-motion — no `!important` needed
on transition properties declared via CSS custom property. Verify this is effective.

## Accessibility Contract (A11Y-02, COMP-06)

### Contrast Requirements

| Category | Minimum ratio | Applies to |
|----------|--------------|------------|
| Normal text (≤18px normal, ≤14px bold) | 4.5:1 | All body, label, caption text |
| Large text (≥18px normal, ≥14px bold) | 3:1 | Metric numbers, h1-h3 headings |
| UI components / graphics (borders, icons) | 3:1 | Focus rings, dividers, status borders |

All six status triplets verified AA at 4.5:1 by `operator_ui_contrast_test.exs`.
Focus ring ratios: `#256C82` on `#FFFFFF` = 5.92:1; `#F8F4EC` on `#18232B` = 14.57:1.

### Semantic Disabled (COMP-02)

- `<button disabled>` — browser-native: `aria-disabled` computed as true, not focusable.
- `<a aria-disabled="true" class="... pointer-events-none cursor-not-allowed opacity-50">` — for link-styled disabled elements.
- Never use CSS-only disabled appearance without matching semantic attribute.
- Visual reduced affordance: `opacity-50` (matches the brand's "stone" tone for disabled fills).

### Status — Not Color Alone (DATA-05 precursor)

Chips carry their status as **visible text inside the chip** (e.g. "open", "resolved",
"healthy", "down"). The color is additive, not the sole signal. This is the existing
pattern in `chip_class/2` functions — do not remove the text labels when re-skinning.

### Focus Ring Implementation Rule

Every interactive element (`<button>`, `<a>`, `<input>`) carries:
```
class="... po-focus focus:outline-none focus:ring-2 focus:ring-offset-2"
```
`po-focus` sets the CSS variable; the Tailwind utility reads it.
Remove any hard-coded `focus:ring-{color}-{n}` utilities from buttons during Phase 45.
