# Phase 36 Plan 01: Demo State Coverage & Browser Verification

## Objective

Complete the v1.3 demo and verification slice by ensuring the demo app expresses the important Operator UI states and captures desktop/mobile browser screenshots for the generated route experience.

## Tasks

1. Expand and pin demo state coverage.
   - Seeds express active, investigating, resolved, recovery-previewable, guidance-only, warning, action-item, escalation, audit, external-link, and retrospective states.
   - Add source-contract assertions over the seed file so coverage cannot silently regress.

2. Pin generated/demo route parity.
   - Keep demo routes aligned with generator guidance for response, actions, history, preferred detail, and compatibility detail.
   - Extend demo smoke tests to cover `/parapet`, `/parapet/actions`, `/parapet/history`, `/parapet/incidents/:id`, and `/parapet/:id`.

3. Add browser screenshot proof.
   - Add a Chromium-based screenshot script that requires a running demo app and captures desktop/mobile PNGs for response, actions, history, and detail routes.
   - Store screenshot evidence under the Phase 36 planning directory.
