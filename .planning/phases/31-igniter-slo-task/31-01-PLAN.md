<objective>
Provide a seamless, flag-based generator for SLOs by creating an Igniter Mix task `mix parapet.gen.slo`.
Purpose: Fills requirement DX-01, allowing operators to easily scaffold Parapet SLO providers instead of hand-writing the boilerplate and registering them manually.
Output: A new Mix task and its corresponding test.
</objective>

<feature>
  <name>parapet.gen.slo generator</name>
  <files>lib/mix/tasks/parapet.gen.slo.ex, test/mix/tasks/parapet.gen.slo_test.exs</files>
  <behavior>
    - Parses arguments to determine the module suffix (e.g., `UserJourney` -> `MyApp.SLO.UserJourney`).
    - Validates presence of either `--objective` (float) or `--threshold` (float).
    - Accepts optional flags: `--good-metric`, `--total-metric`, `--alert-class` (default "page"), `--runbook` (default "https://example.com").
    - Generates a new file `lib/my_app/slo/user_journey.ex` implementing the `Parapet.SLO.Provider` behaviour and returning a `Parapet.SLO.SliceSpec`.
    - Appends the generated module to `config :parapet, providers: [...]` in `config/config.exs`.
    - Returns an Igniter notice advising the user to run `mix parapet.gen.prometheus` to emit the new recording rules.
  </behavior>
  <implementation>
    Use `Igniter.Mix.Task` for the implementation.
    Use `Igniter.Project.Module.module_name_prefix(igniter)` to form the module name.
    Build the provider file content using string interpolation or EEx, and write it via `Igniter.Project.Module.create_module(igniter, module_name, content)`.
    Use `Igniter.Project.Config.configure(igniter, "config.exs", :parapet, [:providers], [module_name], updater: ...)` with a custom zipper updater that handles merging the new module into the existing config list (similar to how `Mix.Tasks.Parapet.Install` does it).
  </implementation>
</feature>
