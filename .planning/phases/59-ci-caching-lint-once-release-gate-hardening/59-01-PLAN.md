<objective>
Apply the three structural edits to `.github/workflows/ci.yml`: (1) add a PLT cache step to the
`lint-once` job so the Dialyzer PLT persists across CI runs (CI-01), confirming lint-once still runs
once on OTP 28 (CI-02); (2) add a top-level `concurrency:` block that cancels superseded PR runs while
never cancelling `main` (CI-03); (3) harden `release_gate` with `if: always()` plus explicit per-job
result aggregation so a failed/skipped upstream can never let the gate silently pass (CI-04). This plan
also holds the CI-05 dual-prefix invariant intact — the `test` job is NOT edited here.

Purpose: This is the release-critical CI backbone. Caching removes the biggest PR latency source, the
concurrency block stops wasted duplicate runs, and the release_gate hardening closes the single-required-
check false-green footgun that a solo-OSS repo relies on as its only safety net.
Output: A modified `ci.yml` with a new PLT cache step, a top-level concurrency block, and a hardened
release_gate run-step. Runtime artifact: a cached `priv/plts` path keyed on OTP+Elixir+mix.lock.
</objective>

| GitHub Actions cache → build inputs | A restored PLT / `_build` cache is trusted by dialyzer/compile without re-derivation |
| Fork PR → CI workflow | Untrusted PR code runs in the CI environment |
