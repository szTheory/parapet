<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| docs -> host archive operations | Docs can cause users to treat Parapet archive maintenance as backup/restore or hide destructive failure distinctions. |
| docs -> host router/auth configuration | Docs can lead users to mount Operator UI outside host-owned authentication and authorization. |
| docs -> generated host-owned UI files | Docs can imply generated files update themselves or that Parapet owns router behavior after generation. |
