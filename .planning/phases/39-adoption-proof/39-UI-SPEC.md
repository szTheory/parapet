# Phase 39 - UI Design Contract

> Visual and interaction contract for the adoption-facing documentation experience. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

This phase is not a runtime UI implementation phase. The contract applies to README/docs reader experience, router snippets, troubleshooting copy, and quality-risk closeout traceability only. It must not prescribe generated Operator UI screen redesigns, new components, new design tokens, new dependencies, auth/router ownership changes, or frontend runtime changes.

## Documentation Reader Contract

| Surface | Contract |
|---------|----------|
| `README.md` | Add concise first-contact archive maintenance and scoped Operator UI mounting guidance. Keep sections short and link to deeper docs instead of turning README into an operations manual. |
| `docs/operator-ui.md` | Preserve host-owned router/auth framing. Include default `/parapet` and scoped `/ops/parapet` examples plus a short gotchas block for stale generated files, incomplete scoped route maps, and missing authenticated pipeline/live session protection. |
| `docs/troubleshooting.md` | Use existing Q&A support style. Add fuller recovery steps for archive failures and scoped UI mounting failures, with exact field names and paths. |
| `.planning/QUALITY-EVALUATION.md` or close artifact | Add a dated closeout trail that maps the named top risks to Phase 37, Phase 38, and Phase 39 evidence without rewriting the original audit narrative or claiming unrelated risks are closed. |

Reader interaction requirements:

- Copy-paste examples must be complete, fenced, and immediately followed by one sentence explaining the ownership boundary.
- Archive commands must include `mix parapet.archive`, `mix parapet.archive --days 30`, and `mix parapet.archive --path priv/parapet/archive.jsonl`.
- Router examples must include the complete generated route map for both `/parapet` and `/ops/parapet`.
- Troubleshooting sections must name the first visible symptom, the likely cause, and the next command or file to inspect.
- Cross-links must point readers from README to `docs/operator-ui.md` and `docs/troubleshooting.md`, and from Operator UI gotchas to troubleshooting recovery details.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Run archive maintenance |
| Empty state heading | No resolved incidents matched the retention window |
| Empty state body | The archive run can still return a successful summary with zero selected, archived, and deleted records. Check `retention_days`, `cutoff`, and incident status before changing retention. |
| Error state | Archive failed at `stage=<stage>` for `run_id=<run_id>`. Inspect `path`, `manifest_path`, selected/archived/deleted counts, and `reason`, then rerun after fixing the file, repo, retention, or mount issue. |
| Destructive confirmation | None in this phase. Docs must explain the existing archive prune boundary, but must not add new destructive UI or confirmation behavior. |

Required exact phrases and facts:

- "Parapet archive maintenance is operational evidence export/prune for Parapet-owned records, not host backup/restore."
- "Retention currently means resolved incidents created before the cutoff (`inserted_at < cutoff`), not incidents resolved before the cutoff."
- "Generated Operator UI files are host-owned."
- "Host apps own authentication, authorization, pipelines, live sessions, and router scopes."
- "Scoped support does not require a generator flag, Parapet router abstraction, stable public API change, or dependency change."
- "Generated local links derive from `operator_base_path`, so the same host-owned files can work at `/parapet` or `/ops/parapet`."

Troubleshooting copy must cover:

- Missing `config :parapet, :repo`.
- Invalid `--days` or unusable `--path`.
- Write, verify, publish, manifest, and delete-stage archive failures.
- Safe rerun expectations after a failed archive.
- Stale generated UI files from before scoped route support.
- Scoped mounts that omit authenticated pipeline or `live_session` protection.
- Broken local links caused by mounting only part of the Operator UI route map under a nested scope.

## Router Snippet Contract

Default mount must remain copy-pasteable as `/parapet`:

```elixir
scope "/", MyAppWeb do
  pipe_through [:browser, :require_authenticated_user]

  live_session :parapet_operator,
    on_mount: [{MyAppWeb.UserAuth, :ensure_authenticated}] do
    live "/parapet", MyAppWeb.Parapet.OperatorLive, :index
    live "/parapet/actions", MyAppWeb.Parapet.OperatorLive, :actions
    live "/parapet/history", MyAppWeb.Parapet.OperatorLive, :history
    live "/parapet/incidents/:id", MyAppWeb.Parapet.OperatorDetailLive, :show
    live "/parapet/:id", MyAppWeb.Parapet.OperatorDetailLive, :show
  end
end
```

Scoped mount must remain copy-pasteable as `/ops/parapet`:

```elixir
scope "/ops", MyAppWeb do
  pipe_through [:browser, :require_authenticated_user]

  live_session :parapet_operator,
    on_mount: [{MyAppWeb.UserAuth, :ensure_authenticated}] do
    live "/parapet", MyAppWeb.Parapet.OperatorLive, :index
    live "/parapet/actions", MyAppWeb.Parapet.OperatorLive, :actions
    live "/parapet/history", MyAppWeb.Parapet.OperatorLive, :history
    live "/parapet/incidents/:id", MyAppWeb.Parapet.OperatorDetailLive, :show
    live "/parapet/:id", MyAppWeb.Parapet.OperatorDetailLive, :show
  end
end
```

Interaction rule: all local Operator UI routes must be mounted under the same base path. If the index route is nested under `/ops/parapet`, actions, history, and detail routes must be nested under the same `/ops` scope.

## Archive Maintenance Contract

Archive docs must present the command surface in this order:

```bash
mix parapet.archive
mix parapet.archive --days 30
mix parapet.archive --path priv/parapet/archive.jsonl
```

Success copy must name these returned JSON fields:

- `status`
- `run_id`
- `path`
- `manifest_path`
- `retention_days`
- `cutoff`
- `selected_count`
- `archived_count`
- `deleted_count`
- `skipped_count`
- `bytes_written`
- `checksum`

Failure copy must name these message fields:

- `stage`
- `path`
- `run_id`
- `selected`
- `archived`
- `deleted`
- `manifest_path`
- `reason`

Boundary rule: docs must not describe the archive as preserving host domain rows, external provider records, telemetry samples, Prometheus state, Grafana state, object-store contents, or a restore workflow.
