### E2E flows (4/4 complete)
1. **New install** → `parapet.install` → `gen.spine` → `resolve_prefix` → sentinel `CREATE SCHEMA` + prefixed DDL → `mix ecto.migrate` lands all six tables in `parapet`. Demo smoke test asserts via `information_schema.tables`.
2. **Track A (stay on public)** → `config :parapet, schema_prefix: nil` + `mix deps.compile parapet --force` → `__prefix__/0` = nil → queries land in `public`. Doctor catches config-set-but-not-recompiled drift.
3. **Track B (schema move)** → `mix parapet.gen.schema.move` → reversible single-transaction `SET SCHEMA` up/down with pre-flight abort guard + second-move refusal. Round-trip DB test proves FK cascade + partial indexes intact.
4. **Doctor drift** → compares compiled `__prefix__()` vs runtime `normalize(get_env)`, emits the exact `mix deps.compile parapet --force` remediation; recompile string asserted identical to the doc.
