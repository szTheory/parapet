## Overview

Operationalized the existing text-only brand research (`prompts/parapet-brand-identity-deep-research.md`, 1,874 lines) into a shippable, self-contained, repo-lean HTML brand book under `brandbook/` — with a hand-authored corbelled-tower stacked-emblem logo (Space Grotesk, outlined to paths), design tokens (CSS + JSON), marketing/UI collateral examples, and a zero-config replacement of the off-brand HexDocs logo + favicon. SVG/HTML/CSS/JSON only — zero rasters, zero font binaries; final footprint 192 KB (≤ 250 KB budget). The public API and telemetry contract were untouched.

## Milestone Summary

**Decimal Phases:**

None — phases 40-43 are sequential, no insertions.

**Key Decisions:**

- v1.5 scope: brand book and logo system only — no new runtime deps, public API changes, or library behavior changes; the public surface stays frozen.
- Logo constraints (user-stated, non-negotiable): no rectangular background cage; unified mark+type (never icon-left-of-plain-text); no subtitle on the primary lockup (separate optional tagline lockup); ≥1 fully-integrated typemark; hand-authored SVG.
- Repo-lean constraint: SVG/HTML/CSS/JSON only — zero rasters, zero font binaries; size budget ≤ ~250 KB for `brandbook/`.
- Phase 41 ends with a hard human gate (LOGO-04): user selects one direction before any downstream phase runs (resolved — D-003 locked S2, the stacked-emblem identity).
- Source of truth: `prompts/parapet-brand-identity-deep-research.md` — operationalize only; no re-derivation of brand strategy.
- HexDocs swap is zero-config path-stable: `docs/assets/parapet-logo.svg` and `docs/assets/favicon.svg` paths unchanged so `mix.exs` doc block requires no edits.
- Logo outlined to paths (font-independent) so assets render identically without font binaries in the repo.

**Issues Resolved:**

- Replaced off-brand HexDocs logo/favicon (Tailwind slate `#0f172a`/`#38bdf8`, Arial, rectangular cage, detached lockup) with the on-brand corbelled-tower mark.
- Resolved 16px favicon legibility before logo selection (proven in monochrome + thumbnail galleries).

**Issues Deferred:**

- Self-hosted webfont bundle (`@font-face` IBM Plex woff2) for pixel-consistent offline rendering — requires font binary (excluded by repo-lean constraint).
- Raster exports (PNG/ICO favicons, OpenGraph social-card images) — raster-free constraint for this milestone.
- Token → Tailwind/daisyUI theme generator and HEEx component snippets — separate milestone scope.
- Retheme the generated Operator LiveView UI to the new tokens — host-owned, separate milestone.
- Animated/motion logo, Figma source-of-truth, multi-page PDF brand book — out of scope for v1.5.

**Technical Debt Incurred:**

- None. The brand book is self-contained; no source code, public API, or telemetry contract touched.
